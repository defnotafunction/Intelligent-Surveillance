# Intelligent Surveillance
- **Start Date:** [8/8/2026]
- **Status:** [In Progress]

## Overview
- This project is an AI-powered program for surveillance, it will use a camera and microphone as sensors to adapt to a certain environment, and detect humans and irregularities.

## Features to add
- [X] **Facial Recognition and Memory:** The program will store information about known faces, and track and identify unknown faces using density clustering.
- [X] **Controller Handling for Configuration:** A game controller will have its inputs mapped to certain outputs that activates certain functions of the program.
- [X] **Recording + Alarm:** This program will start recording during specified events such as people being spotted during curfew, and it will sound an alarm at certain events.
- [X] **Environmental Adaption:** A model will be trained to spot anamolies or irregularities in sound. It will be able to be retrained.
- [] **LLM API Requests / Speech Recognition:** The program will listen for pre-defined commands once activated to or send a request to an LLM API to response to commands and words.
